# Project instructions

- The user requires all future changes for this project to be committed and synchronized to https://github.com/hyunsikhwang/solar-system.git.
- GitHub is the canonical source for ongoing changes. Keep the existing Sites source remote as a separate publishing remote; never replace the Site identity or URL.
- Preserve `.openai/hosting.json` project_id. Use Sites skills for website edits and deployment.
- Before edits, inspect the current GitHub default branch and reconcile newer remote changes. Never force-push over user changes.
- Include required textures, third-party licenses, and attribution with source changes. Do not commit credentials, temporary archives, caches, or local environment files.
- If GitHub synchronization is blocked, report it explicitly; do not claim that a local or Sites-only commit is on GitHub.
- This is a buildless static app. Validate JavaScript syntax and changed local asset references; validate orbital math for changes to orbit calculations.
- Keep existing published behavior and scientific-model caveats unless the user requests a change.
